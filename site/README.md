# TADRIS LAB — تصميمات HTML ثابتة (أكاديمية Atheer)

صفحات عامة مطابقة للمنصة الحالية. لا تحتاج npm.

**المصدر المتزامن:** `designs/tadrislab-public/`  
أعد التوليد: `php designs/tadrislab-public/_generate.php`

## التشغيل (XAMPP)

القاعدة: `http://localhost/tadrislab/site/`

| الصفحة | الملف |
|--------|------|
| الرئيسية | `index.html` |
| من نحن | `about.html` |
| تواصل | `contact.html` |
| الكورسات | `courses.html` |
| تفاصيل كورس | `course-show.html` |
| المدربون | `instructors.html` |
| ملف مدرب | `instructor-show.html` |
| التصنيفات | `categories.html` |
| المجموعات | `groups.html` |
| الأسعار / تقييم | `pricing.html` |
| دخول | `login.html` |
| تسجيل | `register.html` |
| لوحة الإدارة (مرجع) | `admin/index.html` |

أسماء المتجر القديمة (`cart.html`, `product.html`, …) تعيد التوجيه للصفحات الأكاديمية.

## الهوية

Ink `#0b1220` · Accent `#0f5c57` · Metal `#b08d57` · IBM Plex Sans Arabic  
أصول: `assets/css/atheer.css` + `assets/js/atheer-tailwind-config.js`
